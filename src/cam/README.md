# CAM

CAM is short for Communication Accelerator for Matrix. It is a high performance communication acceleration library on Ascend superpod for LLM traning and serving. CAM provides EP (Expert Parallelism) communication acceleration kernels, high-performance KVCache transmission for PD separation and KV pooling scenarios, the AFD (Attention & FFN separation) communication acceleration, the RL weights transfer and so on.
